# Crosssave 26.1.1：经验熔铸

**⚠️ 测试版模组，单人专用。使用前请备份源存档和目标存档。迁移可能造成存档损坏、物品丢失或其他不可预料的问题。模组不会自动备份存档。**

模组名称为 `Crosssave`，ID 为 `crosssave`。运行环境固定为 **Minecraft 1.20.1、Fabric、Java 17**；Yarn 固定为 `1.20.1+build.10`。Gradle 项目版本与加载器元数据版本均为 `26.1.1`。`26.1.1` 是模组版本，不能据此选择 MC 26.x。

本版重构经验的保存与合并逻辑，修正正式 JAR 的 Mixin 映射打包配置；保留原有迁移、界面、特效、音效、多语言及网络行为，之前的项目保持不变。

经验值按总点数合并，因原版经验曲线，高等级合并收益递减。

## 26.1.1 经验规则

源玩家与目标玩家分别根据当前经验等级和经验条进度换算为总点数，相加后用 Minecraft 1.20.1 原版经验曲线反算等级和当前等级进度。不直接相加等级，也不再取高值。例如两个零进度的 30 级玩家各有 1395 点，合并为 2790 点，即 39 级另加 63 点（进度为 63/193）。

新快照同时保存等级、进度及总点数并校验一致性，保留完整物品 NBT。完整快照写入、读回与源物品验证成功后移走源经验；失败回滚恢复原等级、进度和计数，避免往返迁移复制经验。嵌套物品安全重做先恢复目标原经验，再重新合并，不能重复加点。

兼容旧版只有等级的待迁移快照，按记录等级的零进度读取；旧文件未记录的经验条无法补回。总点数使用 long 运算，避免两个 int 点数求和溢出；超出原版等级运算或经验条精度范围时中止并沿用原有回滚，不静默丢失经验。

## 使用与数据

先备份源存档与目标存档。在单人游戏中按 K，选择目标存档并确认即可自动迁移。若使用手动命令保存，则需自行退出当前存档并进入指定目标。命令不检查权限等级。

目标存档的文件夹名和玩家 UUID 必须同时匹配后才读取待迁移 NBT；不匹配时保留文件，不执行恢复。目标存档应安装与源存档相同的物品模组，否则无法恢复的物品会中止迁移。

运行时路径全部从 `MinecraftClient.getInstance().runDirectory` 派生：配置在 `config/crosssave.json`，数据在 `crosssave/<玩家 UUID>.nbt`，待迁移元数据在 `crosssave/pending.json`，存档目录为 `saves`。

```json
{
  "disclaimerAccepted": true,
  "key": "K",
  "noiseEnabled": true,
  "noiseManualOverride": false,
  "soundEnabled": true
}
```

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `disclaimerAccepted` | `false` | 历史确认记录；无论是否为 true，每次启动仍显示免责声明 |
| `key` | `"K"` | 存档列表快捷键 |
| `noiseEnabled` | `true` | 噪点开关，false 始终禁用 |
| `noiseManualOverride` | `false` | 手动选择优先标记；点击设置开关后变为 true，开启时强制全密度，关闭时禁用 |
| `soundEnabled` | `true` | 声呐加载音效开关 |

设置界面实时保存开关；保存失败保留原设置并提示。恢复自动噪点模式可将 `noiseManualOverride` 改为 false 后重启。声呐文件为 `src/main/resources/assets/crosssave/sounds/sonar.ogg`，生成与转换说明见 [SONAR_GENERATION.md](SONAR_GENERATION.md)。

## 构建与产物

使用项目内已配置好的 Java 17 和本地依赖缓存。双击 `build.bat`，或在项目目录执行：

```bat
gradlew.bat --offline --no-daemon --max-workers 2 clean build
```

`build.gradle` 保留惰性归档命名规则 `Crosssave-v${project.version}-mc1.20.1`；最终项目版本在 `settings.gradle` 中设置为 `26.1.1`。未新增依赖，`gradle.properties` 保持不变。固定生成 `crosssave-refmap.json` 并在构建时验证正式 JAR 中所有 Mixin 映射，避免归档改名后生产环境缺少映射。

正式 JAR：`build/libs/Crosssave-v26.1.1-mc1.20.1.jar`。另有同名加 `-sources` 的源码包；安装时选择正式 JAR。构建日志位于 `.build-logs/build.log`。
